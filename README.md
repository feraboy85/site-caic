# Site CAIC — Versão 1

Primeira versão do portal público da **Escola Municipal Professor José Antonio Flygare Telles (CAIC)**.

## Estrutura
- `index.html` — página principal responsiva
- `assets/caic-aereo.jpg` — foto de destaque enviada para o projeto
- `assets/logo-caic.png` — logo CAIC com #TUDOdeBOM
- `assets/calendario-2026.jpg` — prévia do calendário escolar
- `docs/calendario-escolar-2026.pdf` — calendário completo em PDF

## Publicação
Envie o conteúdo desta pasta para o repositório do site. A página funciona como site estático e não exige servidor ou banco de dados.

## Conteúdos que podem ser atualizados depois
- Avisos e notícias
- Fotos de projetos/eventos
- Telefones e contatos
- Redes sociais
- Calendário 2027
- Área de documentos e matrículas

## Observação
O mapa usa incorporação do Google Maps e exige internet para aparecer.
